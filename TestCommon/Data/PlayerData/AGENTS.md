# PlayerData test data

Player build output used by the UnityDataTools test suites, kept in a subfolder per Unity version (e.g. `2022.1.20f1`). Each holds the serialized `level0` scene file and its `.resS` streaming resource.

Generated by the `UnityProjects/Baseline` project - run **Tools > Generate PlayerData** there (builds a player from `OtherScene.unity` and copies `level0` here under the Unity version). This requires the `ForceAlwaysWriteTypeTrees` diagnostic switch to be enabled. See that project's `AGENTS.md`.
